# Desafio 2 – Plano de Segurança e Acessos

Este desafio consiste na criação de um plano de segurança para uma empresa fictícia, com foco em:

- Controles de Identidade e Acesso
- Proteção de Aplicações
- Segurança de Rede
- Governança e Conformidade

O objetivo é demonstrar sua capacidade de projetar um ambiente seguro usando boas práticas de cibersegurança.

O conteúdo detalhado está no arquivo `resposta.md`.
